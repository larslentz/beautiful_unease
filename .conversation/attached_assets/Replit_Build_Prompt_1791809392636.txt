LESSON PATH
1. Read the piano roll: pitch vertical, time horizontal, note length is duration, same start is simultaneous, blank space is a rest.
2. Build C minor from C/Eb/G; add D as the ninth. Compare the same phrase with and without D.
3. Add a separate low bass and spread the upper notes: explain a voicing without assuming keyboard technique.
4. Enter the exact eight-bar cue below, chords first, melody second.
5. Explore paired dyads and the half-step fourth-to-third release below.
6. Compare pedal-point harmony, suspended harmony, minor-major seventh color and closed versus open endings.
7. Make controlled variations and extend the loop to a 32-bar cue.
Every lesson has a Listen button, exact event table, visual piano roll, one action to do in FL Studio, plain-language explanation, comparison switch and short listening question. No quizzes that imply a chord has one universal emotional meaning.
